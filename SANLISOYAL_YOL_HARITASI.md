# ŞanlıSosyal — Gelecek özellikler (yol haritası)

Bu dosya fikirleri kaybetmemek içindir; öncelik ve tarih eklenebilir.

## Öncelikli fikirler (senin listenden)

| # | Özellik | Kısa not |
|---|---------|----------|
| 1 | **Streak sistemi** | Her gün paylaşım yapan kullanıcılarla (veya arkadaşınla) artan gün sayacı; kopunca sıfırlanır / yumuşak “kurtarma” opsiyonel. |
| 2 | **Grup kıvılcımı** | Aynı kıvılcımı **2–5 kişiye** aynı anda gönderme; alıcı listesi + tek yükleme veya çoklu hedef `social_posts` / ilişki tablosu. |
| 3 | **Anonim mod** | Şehir radarında **kimliksiz** nokta; `user_id` null veya ayrı `anonymous_posts` + sadece ısı haritası; kötüye kullanıma karşı rate limit / moderasyon düşünülmeli. |
| 4 | **"Urfa'da şu an"** | Canlı aktivite göstergesi (son X dakikada paylaşım sayısı, hafif animasyon, belki mahalle özeti); mevcut radar + `social_posts` zaman penceresi ile beslenir. |

## Daha önce konuşulan diğer başlıklar

- Ana uygulama **Bildirimler** ekranı ile ŞanlıSosyal olaylarının birleştirilmesi / filtrelenmesi  
- **Push bildirimleri** production (EAS, `projectId`, güvenli gönderim)  
- **ŞanlıAsistan** API key / kota  
- Kamera & akış **UX cilası** (orb, geçişler)  
- Kıvılcımda **gönderen tarafı** için tepki özeti (gizlilik kurallarıyla)  
- **ŞanlıSosyal profil** Bento genişletmesi
